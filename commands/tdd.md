Implement the following using strict Test-Driven Development (Red-Green-Refactor):

$ARGUMENTS

Before writing any code:
1. Identify the test framework and test runner for this project
2. Run existing tests to establish a green baseline (if any exist)
3. Break the requirement into the smallest possible testable increments
4. Create a todo list with all increments and their 7 gated phases (RED write, RED verify, GREEN write, GREEN verify, GREEN commit, REFACTOR improve, REFACTOR verify)

Then begin the first Red-Green-Refactor cycle.
